# 积压处置跟踪 3 页口径（待确认）

## 统一口径

- 基准日 = 较新月月末（9月报表 → 2026-09-30）
- 积压天数 = 基准日 - 开始积压时间；缺失退回 入库日期；两者皆缺 → 不入账龄统计，页脚注明
- 不流动 = 最后领用日期距基准日 > 180 天，或从未领用（字段空）
- 金额万元 2 位小数；缺列页出占位页
