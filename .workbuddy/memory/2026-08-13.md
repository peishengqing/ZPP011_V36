  2. 新增 `_bundle_config_path`：仅 exe 模式返回打包内置默认（只读兜底）。
  3. `load_*_config`：持久化文件不存在时回退 `_bundle_config_path`（保证首次启动有默认规则）。
- 用户确认：用 `ZPP011_PROJECT_ROOT` 指向 `E:\zpp011_v2\config`（约定：启动 exe 前须 set 该环境变量，否则回退 exe 同目录 config/）。
