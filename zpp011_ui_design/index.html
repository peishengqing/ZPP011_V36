六项结构性改动

1
标题栏减负，把"制作人"换成"数据上下文"

现状副标题写的是「制作人：裴盛清 | v43.332」——C 端 App 的做派，占着横向黄金位却零信息量。改为「本次分析时间 + 数据源」；公司名降为品牌块下方 10.5px 副行。标题栏 56px → 48px，主标题去掉"云南达利"前缀缩短为「ZPP011 生产偏差分析器」。

2
操作栏三段分层，13 个控件降到 8 个可见

现状把「分析 / 审核」这类主操作和「左侧栏 / 筛选 / 列头筛选」这类视图开关平铺在同一层，还塞着常驻快捷键提示。新版分三段：主操作（分析、审核，实心/描边区分）｜视图开关（4 个 icon-only toggle，带选中态）｜溢出菜单（看板、导出、更多）。快捷键提示降级为状态条右侧的小字 hint，不再抢位。

3
概览从"7 张大卡"改成"KPI 条"，表格拿回 120px

现状 7 张卡片 + 标题行 + 进度条固定吃掉 175px（top_panel 限高 260），而这是要看表干活的工具，表格才是主角。新版把 7 个指标压成一条 54px 的 KPI 带：数值 16.5px 等宽字体 + 11px 说明 + 6px 语义色圆点；可点击的指标带右箭头，hover 才有反馈。展开态仍保留原 7 卡网格。

4
左栏 260px 收到 236px，改为"导航"而非"第二个筛选器"

现状左栏里混着过滤/筛选/快捷/备选料，和右侧 440px 筛选面板功能重叠，用户面对两个独立开关容易迷路。新版左栏只做去向（偏差明细 / 审核队列 / 隔离区 / 替代料 / 车间快捷），所有条件收进右侧筛选抽屉（单一入口）。徽标数字直接挂在导航项上，一眼看到待办量。

5
筛选入口合并为一个抽屉按钮

现状「左侧栏」「筛选」「列头筛选」三个开关各自独立、状态互不相干。新版视图开关做成 icon-only toggle 组并显示选中态，用户始终知道"我现在开着什么"；三个开关的显隐状态统一由同一处管理。

6
底部状态条复活为"选中 + 合计"常驻栏

v43.281 已移除底部合计标签，但审核员每天都要盯"选了多少行、合计差多少钱、还剩多少未读"。新版把这三项放回底部 30px 状态条，右侧补分析时间和版本号——低频信息右置，不再和表格抢注意力。
